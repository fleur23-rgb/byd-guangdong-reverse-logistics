# 数据说明：广东示范情景

`raw/` 保存带版本号的 V2.1 论文案例工作簿；`processed/` 是通过
`scripts/build_inputs.py` 规范化后提交的模型输入。直接运行优化模型时无需再次处理 Excel。

本目录提供的是全国通用模型的数据结构示例及广东示范情景，并非模型只能处理广东数据。迁移到其他省份、城市群或全国分区时，应按相同字段替换来源区域、候选中心、处理设施、运输弧和成本参数。

仓库数据由公开资料估计、空间代理、文献校准参数和情景假设构成，不是比亚迪内部经营台账。除特别说明外，设施坐标采用地市级代理点；弧表同时保留基于 Haversine 公式的代理距离和 OSRM `driving/car` 路网距离。广东正式情景使用 OSRM 距离，代理距离仅用于对照和诊断。

使用数据或地图服务时，请保留原始来源、抓取日期和相应引用，并遵守第三方服务的许可条款。
